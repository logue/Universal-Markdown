# Universal Markdown (UMD) v0.1.1

Released: 2026-05-19

This release includes updates to the package name and metadata for npm compatibility, along with minor documentation improvements.

## Changes

- Updated npm package name to `universal-markdown`.
- Improved build script to ensure package metadata normalization.
- Updated documentation to reflect the new package name.

## Compatibility

- Rust: 1.93.1+
- Edition: 2024
- Targets: native Rust library + `wasm32-unknown-unknown`

## Install

```toml
[dependencies]
umd = "0.1.1"
```
